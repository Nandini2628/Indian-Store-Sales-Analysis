# Indian-Store-Sales-Analysis


## 📌 Project Overview

This project analyzes Indian store sales data using Python and Business Analytics techniques.

## 🎯 Objectives

* Analyze sales and profit performance.
* Compare business performance across regions.
* Compare product categories.
* Perform Pareto Analysis using the 80/20 rule.
* Perform ABC Analysis based on business contribution.
* Generate meaningful business insights and recommendations.

## 🛠️ Tools & Technologies

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

## 📊 Analysis Performed

1. Dataset Understanding
2. Data Preprocessing
3. Data Transformation
4. Region-wise Comparative Analysis
5. Product Category-wise Analysis
6. Box-and-Whisker Plot
7. Pareto Analysis
8. ABC Analysis
9. Business Insights
10. Business Recommendations

## 📁 Files

* `Indian_Store_Sales_Analysis.ipynb` – Python analysis notebook
* `store_sales_data (2).csv` – Dataset
* `Indian_Store_Sales_Analysis.pptx` – Project presentation

## 📈 Key Outcomes

The project identifies high-performing regions, product categories and high-value products using comparative, Pareto and ABC analysis.
